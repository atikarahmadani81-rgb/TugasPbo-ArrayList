# TugasPbo-ArrayList
# Bank System Simulation (Java OOP & ArrayList)

A simple Java console-based banking application demonstrating Object-Oriented Programming (OOP) principles, dynamic data structures using `ArrayList`, and clean console formatting.

---

## 🚀 Features

* **Multi-Customer Support:** Create and manage multiple bank accounts independently (e.g., individual balances and transaction histories for different customers).
* **Core Banking Operations:**
  * **Deposit:** Add funds to the account with automatic balance updates.
  * **Withdraw:** Secure withdrawal validation ensuring users cannot withdraw more than their current balance.
  * **Balance Inquiry:** Real-time checking of the current account balance.
* **Dynamic Transaction History:** Automatically logs all account activities (Initial Balance, Deposits, Withdrawals) using Java's `ArrayList`.
* **Structured Output Design:** Clean console interface featuring custom headers, symbols, and numbered transaction logs.
